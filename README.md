## ▶️ **Running the Notebooks**

The notebooks can be opened directly in **Google Colab** using the **Open in Colab** buttons.

### **Option 1 — Google Colab**

Click the **Open in Colab** button next to the relevant notebook.

### **Option 2 — GitHub**

Open the `.ipynb` file directly from this repository.

### **Dataset Access**

The notebooks use repository-based dataset paths or **GitHub Raw URLs** where applicable.

For example:

```python
import pandas as pd

url = "https://raw.githubusercontent.com/juleuzun/Python_DataScience_Bootcamp/refs/heads/main/Datasets/Assignment_4_ogrenci_calisma_notlari.csv"

data = pd.read_csv(url)

data.head()
```

This approach makes the notebooks easier to reproduce without relying on personal files or Google Drive paths.
