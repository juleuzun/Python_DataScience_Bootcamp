# Lesson 04: Simple Linear Regression

In this lesson, we covered the fundamentals of Simple Linear Regression and built a predictive model using an advertising dataset.

##  Topics Covered
* Data preprocessing and visualization with `matplotlib`
* Splitting datasets into training and testing splits (`train_test_split`)
* Training a `LinearRegression` model using `scikit-learn`
* Evaluating model performance using Mean Squared Error (MSE)
* Visualizing the regression line

##  Files in this Folder
* `linear_regression.ipynb`: The main Google Colab notebook containing all the project code.
* `Advertising.csv`: The dataset used for predicting sales.

##  Key Takeaway
TV advertising budget showed the strongest positive linear correlation with product sales compared to Radio and Newspaper.
